# Security

## Scope

This repository contains no executable code. It consists entirely of Markdown documentation files used as context for an AI agent.

Security concerns relevant to this repo:

- **Incorrect API authentication guidance** that could mislead someone into exposing credentials or using insecure patterns
- **Hardcoded example tokens or credentials** committed to the repository
- **Guidance that understates security risk** for a sensitive configuration (e.g., overly broad token scopes, insecure auth flows)

## Reporting

If you identify a security concern of any of these types, please report it via [GitHub's private vulnerability reporting](https://github.com/virtualrussel/DT_Technical_Specialist/security/advisories/new) rather than opening a public issue.

You can also email `russel.wilkinson@dynatrace.com` directly.

## Response

This is a personal repository maintained on a best-effort basis with no guaranteed response SLA.

For urgent concerns involving Dynatrace product security (not this repo), contact Dynatrace directly through their official security disclosure channels at [dynatrace.com/company/trust-center](https://www.dynatrace.com/company/trust-center/).
